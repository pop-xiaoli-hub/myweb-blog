# MyWeb visual redesign

Type: service (a personal iOS development notebook for readers learning Objective-C and app engineering). Main action: Read the blog.

Deal: sky-paper custom brand palette, using the requested soft sky blue with a pale blue-white ground; Schibsted Grotesk; split hero; solid buttons; photo-led `picture-develops` moment in the memory section; flat grounds, no decorative effects.

## Screens

1. Hero: what the notebook covers, the real city photograph, two published essays, and one main action. One screen.
2. Recent writing: the two real essays as an editorial list with dates, tags and descriptions. One screen.
3. Notebook topics: launch performance, runtime details and working notes, with a quiet code visual. One screen.
4. Memory gallery: one large developing photograph and two supporting frames from the existing album. One screen.
5. Ask the notebook: the existing AI assistant presented as a real interface beside a short explanatory column. One screen.
6. Footer: one reading action, site directory and the current year.

All article, about and archive pages reuse the same light palette, type scale, navigation, buttons and rounded card language.
